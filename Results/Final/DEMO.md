# Reproducible demonstration

Run PowerShell from the repository root. Requirements: the existing four cMIPS input files, Python 3 with matplotlib, and Vivado/XSim 2025.1.1 with Artix-7 device support. No board or paid-only device is required. Native tools need write access to their normal user cache. Projects/checkpoints use `%TEMP%/vl405_final_*` to avoid OneDrive build overhead; reports stay under `Results/Final/`.

```powershell
$vivado = 'E:/2025.1.1/Vivado/bin/vivado.bat'
python lbist/scripts/build_final_sources.py
& $vivado -mode batch -nojournal -nolog -source lbist/scripts/run_final_verification.tcl
```

This is the essential demonstration: generator/phase shifter/filter, all three controllers, scan register, safe isolation, MISR arithmetic/safety, router and lwsw equivalence with/without stalls. Expect `FINAL ESSENTIAL VERIFICATION: PASS`. The lwsw program deliberately terminates through its original WAIT assertion at PC00000038; the runner requires that exact exit plus equal original/scan pipeline state. It is not a generic assertion waiver. Every test has a simulated-time watchdog below100ms.

The full production demonstration and real activity capture run all five approaches for256patterns each:

```powershell
& $vivado -mode batch -nojournal -nolog -source lbist/scripts/run_final_activity.tcl
& $vivado -mode batch -nojournal -nolog -source lbist/scripts/run_final_functional_activity.tcl
& $vivado -mode batch -nojournal -nolog -source lbist/scripts/run_final_fault_demo.tcl
& $vivado -mode batch -nojournal -nolog -source lbist/scripts/verify_final_waveforms.tcl
```

Expect `FINAL PRODUCTION ACTIVITY: PASS` and `FINAL FUNCTIONAL ACTIVITY: PASS`. Each production run compares real functional, scan and MISR interfaces at all processor phases, checks pause/isolation/capture/unload/signatures, and finishes at661.6002us. Functional activity separately captures original and production-scan cores during lwsw. Results, logs and portable WCFGs are under `Verification/`; SAIFs are local under `FPGA_Analysis/power/activity/`.

For synthesis and physical implementation, run sequentially to limit memory use:

```powershell
& $vivado -mode batch -nojournal -nolog -source lbist/scripts/run_final_fpga_analysis.tcl *> Results/Final/fpga_console.log
python lbist/scripts/map_final_saif.py
& $vivado -mode batch -nojournal -nolog -source lbist/scripts/run_final_power.tcl *> Results/Final/power_console.log
& $vivado -mode batch -nojournal -nolog -source lbist/scripts/run_final_power_details.tcl *> Results/Final/power_details_console.log
python lbist/scripts/summarize_final_power.py
python lbist/scripts/build_final_report.py
python lbist/scripts/build_final_pdf.py
```

The first Tcl flow creates isolated A/B/C projects on the same part, with common clock/reset settings, runs synthesis/place/route, and saves reports/checkpoints. Timing may fail even when all commands finish successfully. The second reads those routed checkpoints and own-design activity, records unmatched nets and power confidence, and never reruns routing. The mapper changes hierarchy names only and asserts that all switching records remain unchanged. Check `power/status.csv`, annotation reports and the explicit timing summary before interpreting any number.

The additional fault demo repeats Basic fault1 from the original universe; it does not expand the campaign. The waveform audit reopens all six newly generated WDB/WCFG pairs. `python lbist/scripts/audit_final_native.py` independently rechecks the20 new native cases, response traces and activity windows after these demonstrations are present.

To inspect waveforms, open the matching local WDB and WCFG in Vivado. For example:

```tcl
open_wave_database Results/Final/Verification/Activity/waveforms/approach_2.wdb
open_wave_config Results/Final/Verification/Activity/waveforms/approach_2.wcfg
```

The portable figures in the report are sufficient for review without Vivado. The historical45 waveform figures have been independently checked against recorded VCD intervals. WDBs/VCDs are regenerated by the activity runner rather than committed as large binaries.
